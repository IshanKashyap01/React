# Webpack

- It is a free and open source static module bundler for Javascript

- It can compile JSX and SASS as well and bundle all JS files into a single one

- To function properly, it requires the following three things:

    1. *Entry point* to your application

    2. *Loaders* to transform files into valid modules that webpack doesn't
    natively support

    3. *Output directory* to put the resulting files into
