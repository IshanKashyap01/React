# Create React App

- Now deprecated, it is a build tool for react that comes preconfigured

- To install it locally, use `npm install create-react-app`

- Use the `-g` flag to install any node module globally

- To use a locally installed `create-react-app`, use `npx`:

```bash
npx create-react-app hello-world
```

## `npm` Commands

1. `npm start` starts the development server

2. `npm run build` bundles the app into static files for production

3. `npm test` starts the test runner

4. `npm run eject` removes this tool, copies build dependencies, config files,
and scripts into the app directory; irreversible
