# Directory Structure

1. `node_modules` stores all the installed libraries and dependencies

2. `public` contains the static files that will be served to the browser

    - `favicon.ico` logo displayed at the browser's tab

    - `index.html` the HTML file where your React app will mount

    - `manifest.json` project metadata

3. `src` contains your source code including React's `.jsx` files

    - `index.js` entry point of your application

    - `App.js` your main react component that gets rendered into root

    - `App.css` CSS for your main component

    - `index.css` global CSS styles applied across the app

4. `package.json` manifest that contains the project's identity, dependencies,
commands and configurations

5. `package-lock.json` contains every bit of information needed to run your app
in another system
