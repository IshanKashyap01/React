# Introduction to React Router

- In MPAs, whenever you click a link to another page, the URL changes

  - This is called server-side routing

- However, that does not happen in an SPA as you're on the same page regardless
of the component displayed

- To achieve the same effect in SPAs, we use the *client-side routing*

```bash
npm i react-router-dom
```

- However, React doesn't support it so we use the `React-Router-DOM` library
