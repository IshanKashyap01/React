# Styling in React

- In MPAs, you can have separate CSS for each page but SPAs culminate those
different pages into one

- Moreover, CSS is scoped globally, regardless of which JS file you import them
into

- Therefore, in sufficiently large SPAs, you'll run into naming conflicts in
CSS

- To prevent this, you can use the following methods:

    1. *Inline Styles*

    2. *Styled Components*

    3. *CSS Modules*
