# Introduction to React

- It is a Javascript library for building user interfaces

- It is component-based i.e. lets you create reusable components and assemble
them however you like

- It helps in creating *single-page applications* efficiently

- It is declarative i.e. describes the desired outcome not the steps to achieve
it

- It eliminates the need for manual DOM manipulation

## Single vs Multiple Page Application

- SPA is a web app that loads a single page and updates it using JS APIs
instead of reloading or directing to a different page

- MPAs support Search Engine Optimization natively as every page has its own
URL, metadata and content ready for crawlers

## Virtual DOM

- React keeps a UI tree in its memory that abstracts away DOM operations

- When you tell React to make a change in the UI, it handles all the operations
on its own through this V-DOM
