# Introduction to Firebase

- Firebase is an cloud platform that provides *backend-as-a-service*

- It provides **Firebase SDK** that sits in your client-side and connects to
the cloud service

- It provides two NoSQL solutions: **Realtime Database** and **Cloud**
**Firestore**

- They're both *real-time database* i.e. users are notified as soon as data is
updated

- While Realtime DB stores data as one giant *nested JSON tree* whereas
Firestore stores it in *documents within collections*

- Cloud Firestore is the newer, recommended database
